## Deploying in under five minutes

**Netlify Drop**, go to <https://app.netlify.com/drop> and drag the unzipped folder onto the
page. You get a public URL immediately, no account needed to start.

**GitHub Pages**, push the folder to a repository, then Settings → Pages → deploy from the
`main` branch, root folder.

**Vercel**, `vercel deploy` from inside the folder, or drag and drop through the dashboard.

Whichever you use, paste the URL into the table above and re-export this file as the PDF
required for File 3, or fold it into the documentation PDF.
